## 媒体处理

输入 MOV：1080×1984，27.703 秒，H.264 + HE-AAC。全片 829 个可检测帧均检测到相同黑边范围，实际画面为 x=0、y=702、1080×580。只移除这两条黑边，保留中文字幕、画面内容和原声，不剪掉片段。

交付 MP4：1080×580，H.264 High / level 4.0 + AAC-LC；编码封装后时长 27.749 秒。约 5 MB，内嵌于约 7 MB 的单文件 HTML，不需要连接第三方媒体地址。视频仅最终通关时加载；播放时游戏保持暂停，背景音乐受现有暂停门控停止。

## 未验证 / 限制

- 没有用真实 iPhone / Android、Safari / Firefox 或低性能手机测试。模拟窗口尺寸不能替代真实设备验证。
- 浏览器测试工具禁止访问 file: 协议，因此双击本地 HTML 的播放未实际验证；已在本机 HTTP 页面测试同一内嵌视频。不绕过工具限制。
- 原声轨道及非静音播放状态已核对，未通过人工监听确认用户实际扬声器输出。
- 播放错误会显示重试 / 跳过，不阻塞通关；错误分支为模拟媒体错误事件验证。
- 本轮通关测试使用隔离存档与测试页完成目标，没有人工从第一关连续实战到第五关。过去的移动、武器、碰撞和压力测试是历史结果，本轮未重新全部运行。

上述记录为发布前的本地验证；线上发布验证另行记录。
