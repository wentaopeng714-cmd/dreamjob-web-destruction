# 梦想直聘 · 网页破坏游戏

一个把中文招聘网页变成可破坏地形的五关浏览器游戏。小火柴人踩着文字移动，用枪、榴弹和橡皮擦拆掉页面，在沟通记录与逐步加压的战斗中获得武器成长。

**[在线试玩](https://wentaopeng714-cmd.github.io/dreamjob-web-destruction/)** · **[OPF 与设计理念](DESIGN.md)** · **[测试记录](tests/TEST_RESULTS.md)**

## 体验重点

- 文字本身就是地形：标题、正文、链接、按钮、图片和侧栏可被攻击破坏；消失处留下缺口，其余内容保持原位。
- 小角色进入正常网页，页面的秩序感与破坏反馈形成对比。各关保持不同颜色、沟通内容和压力等级。
- 三种武器各有用途，拆字解锁改造，装备跨关继承；枪械成长同步强化榴弹与橡皮擦。
- 第二关起采用有限波次与明确击杀标准，最后挑战巨大虚构企业家 Boss。通关可以继续拆，不会重启怪物刷新。
- 文字被拆光后仍可升降与悬停；提供手机摇杆、射击区域和横竖屏布局。
- 最终胜利提供用户指定的约 28 秒影片，可播放、跳过、重播，再查看成绩或继续拆。

## 操作

桌面：A / D 移动，W / 空格上升，S 下降，松开悬停；鼠标瞄准并按住射击，1 / 2 / 3 切武器，R 回位，Esc 暂停，滚轮浏览长页。手机：左摇杆移动，右射击区按住射击并可拖动瞄准。顶部设置可以选择关卡。声音需要首次互动后开启。

## 源码与构建

网页不需要第三方 CDN、账号或后端。页面图片、音乐与结局影片已经内嵌，`docs/index.html` 可直接作为静态文件发布。

使用 Python 3 重建：

```sh
python3 build.py
```

构建沿用现有源码：`work/enhanced-five/` → `work/boss-air/` → `work/mobile-wave/` → `work/level-standards/` → `work/finale-video/`。媒体已准备好，构建无需 FFmpeg；只有重新准备指定影片时才需要 FFmpeg。

最新流程检查 178 项通过；历史碰撞、武器和压力测试不作为本次重新测试结果。真实 iPhone / Android、Safari / Firefox 与低性能设备仍待验证，见测试记录。

招聘与聊天内容为虚构预设；Boss 为虚构角色。进度在浏览器本地保存，不会提交真实应聘信息。结局影片由项目作者提供；本仓库不对该影片声明原创或额外授权。
