# 梦想直聘 · 网页逆袭

把中文招聘与沟通页面变成向上推进的文字战场。小火柴人从页底出发，原网页文字逐步攻击角色；移动躲避、自动射击、拆字成长，最终挑战三阶段 Boss。

**[在线试玩](https://wentaopeng714-cmd.github.io/dreamjob-web-destruction/?level=1)** · **[OPF 与设计理念](DESIGN.md)** · **[最新测试记录](tests/TEST_RESULTS.txt)**

## 当前版本

- 五个主题开始界面，可直接选择关卡。每局用约 5.8 秒从真实网页顶部浏览到角色位置；可跳过或关闭动画。
- 保留中文网页排版与小火柴人比例。文字离开后留下缺口，其他内容不重排；销毁后同步移除碰撞。
- 自动攻击，移动躲避。按钮或数字 1 / 2 / 3 切换主武器，另外两把低频自动支援。枪、榴弹、橡皮擦联动成长，装备跨关继承。
- 必须向上推进并清完本页全部文字与标题；第五关还须击败 18000 生命的三阶段 Boss。通关后可以下一关、结束或自由拆。
- 绿色血包靠近拾取恢复 2 格生命。满血不消耗、16 秒过期、有限掉落；保持在镜头内角色可到达的区域。
- 五关不同网页、音乐及递进难度；最终影片可播放、跳过和重播。手机摇杆支持横竖屏。

## 操作

桌面：方向键或 WASD 移动，1 / 2 / 3 切主武器，Esc 暂停。手机：左摇杆移动，点击武器按钮切换。战斗自动攻击，升级出现时选择改造。自由拆模式的鼠标操作见游戏内提示。声音需互动后开启。
